# 👶 Guia Passo a Passo: Levando o FitPulse para o Mundo

Olá! Eu sou o seu assistente e vou te ensinar a levar esse app para fora daqui, de um jeito bem simples.

## 1. O que é o GitHub? (A nossa Caixa de Brinquedos)
O GitHub é onde guardamos o código para ninguém perder.
- **Como fazer:** No menu do AI Studio, procure por **"Export to GitHub"**.
- **O que acontece:** Ele cria uma conta para você e guarda tudo lá. É automático e seguro!

## 2. O que é o Firebase? (O nosso Cérebro)
É aqui que guardamos os seus treinos e o seu peso.
- **Eu já configurei para você!** Mas se um dia você quiser criar o seu próprio:
  1. Vá em [console.firebase.google.com](https://console.firebase.google.com).
  2. Crie um projeto chamado "FitPulse".
  3. Ele vai te dar umas chaves (códigos).
  4. Você cola essas chaves no arquivo `firebase-applet-config.json` que está aqui no projeto.

## 3. Como colocar no Kodular? (A nossa Moldura)
O Kodular faz o app virar um ícone no seu celular Android.
- **Passo 1:** No Kodular, crie um novo projeto.
- **Passo 2:** Procure na lista de peças (componentes) por **"Web Viewer"**.
- **Passo 3:** Arraste ele para a tela do celular.
- **Passo 4:** No lugar escrito "Home URL", você vai colar o link do seu aplicativo (o link que termina em `.run.app`).

## 4. Como publicar na internet?
Para o app funcionar no Kodular, ele precisa estar "vivo" na internet.
- Aqui no AI Studio, quando você clica em **"Share"** ou **"Deploy"**, ele te dá um link. Esse link é o que você usa para sempre!
